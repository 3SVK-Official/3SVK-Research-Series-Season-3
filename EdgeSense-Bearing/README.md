# EdgeSense-Bearing

## Lightweight Cloud-Edge AI for Real-Time Bearing Fault Diagnosis

EdgeSense-Bearing is a machine-learning based predictive-maintenance research project for classifying bearing conditions from motor vibration signals.

The project investigates a software-based edge-cloud workflow in which vibration signals are divided into fixed-size windows, compact statistical features are extracted, and machine-learning models are used for bearing-condition classification.

The project also measures inference latency, process memory, and the theoretical reduction in transmitted payload when compact features are used instead of transmitting the complete vibration window.

---

## 1. Problem Statement

Industrial motor bearings can develop faults that change their vibration behavior.

Continuous transmission of high-frequency vibration data to a centralized processing system can create substantial data-transfer requirements.

This project investigates whether statistical vibration features can be extracted locally and used for fault classification while substantially reducing the amount of information represented for transmission.

---

## 2. Objectives

The main objectives are:

1. Process motor-bearing vibration signals.
2. Divide vibration signals into fixed-size windows.
3. Extract statistical features from each window.
4. Train and compare multiple machine-learning models.
5. Evaluate classification using accuracy, precision, recall, and F1-score.
6. Measure inference latency and process RSS memory.
7. Compare raw vibration payload with compact feature payload.
8. Evaluate a local software-based edge-cloud data-flow.

---

## 3. Bearing Classes

The current experiment uses four classes:

- Normal
- Inner Race Fault
- Ball Fault
- Outer Race Fault

---

## 4. Dataset

The project uses the Case Western Reserve University (CWRU) Bearing Data Center dataset.

The CWRU Bearing Data Center provides experimental vibration data for normal and faulty bearings. The documented fault categories include inner-race, rolling-element/ball, and outer-race faults, with experiments performed under multiple motor loads and speeds. 

The current implementation uses drive-end vibration signals from the selected MATLAB `.mat` recordings.

### Dataset attribution

Case Western Reserve University Bearing Data Center:

https://engineering.case.edu/bearingdatacenter/

---

## 5. Methodology

The main processing pipeline is:

```text
CWRU Vibration Data
        |
        v
Signal Loading
        |
        v
Fixed-Size Windowing
        |
        v
Feature Extraction
        |
        v
Machine Learning
        |
        v
Bearing Fault Prediction
```

Each vibration window contains 1000 samples.

Four statistical features are extracted from each window:

- Mean
- RMS
- Standard Deviation
- Peak Amplitude

---

## 6. Edge-Cloud Architecture

### Cloud-style processing

```text

        v

        |
        v

```

### Edge-style processing

```text
Raw Vibration Window
        |
        v
Feature Extraction at Edge
        |
        v
Compact Feature Payload
        |
        v
Data Representation / Transmission
        |
        v
Machine Learning
        |
        v
Prediction
```

The edge-cloud experiment is a local software emulation.

It does not measure real Internet latency or performance on a physical edge device.

---

## 18. Limitations

The current implementation has several limitations:

- The edge environment is software-simulated.
- No physical edge device is used.
- No real Internet/network latency is measured.
- The payload reduction result is a theoretical/local comparison.
- Process RSS is used as a system-level memory measurement.
- The experiment uses a selected subset of available CWRU recordings.
- The reported 100% model results apply only to the current grouped test split.
- Generalization to different machines, sensors, environments, and operating conditions has not been established.

---

EdgeSense-Bearing implements a reproducible machine-learning pipeline for bearing fault classification using vibration signals.

The current experiment demonstrates the complete workflow from vibration-data loading and windowing through feature extraction, model comparison, system benchmarking, and software-based edge-cloud payload analysis.

The project provides a foundation for future validation on physical edge hardware and real-time industrial sensor data.
