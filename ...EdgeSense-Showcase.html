EdgeSense-Bearing

Lightweight Cloud-Edge AI for Real-Time Bearing Fault Diagnosis

A machine-learning research project that analyzes bearing vibration signals and classifies bearing conditions using statistical features.

View Python Code ↗ View Results ↗

Project Overview

Signal Processing

Vibration signals are divided into fixed-size windows of 1000 samples.

Feature Extraction

Mean, RMS, standard deviation and peak summarize each signal window.

Fault Classification

Four classes: Normal, Inner Race Fault, Ball Fault and Outer Race Fault.

Model Evaluation

Logistic Regression, Decision Tree, KNN and Random Forest are compared.

Edge-Cloud Concept

Four extracted float64 features occupy 32 bytes compared with 8000 bytes for a 1000-sample float64 window. This represents a theoretical payload-size reduction of 99.6%, not a measured real-network result.

The reported accuracy applies to the current test split. This showcase does not run live predictions; that requires a deployed Python backend.
