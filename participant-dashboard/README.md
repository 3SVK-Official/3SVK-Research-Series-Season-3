# 3SVK Participant Dashboard — Frontend Starter

This package is a standalone React + TypeScript + Vite starter based on the Participant Dashboard requirements supplied by SIRIPURAM VINOD KUMAR.

## Included

- Responsive participant dashboard
- Dark/light mode
- Participant profile overview
- Submission milestone tracker
- Repository verification view
- Verification event history
- Milestone/credential badge viewer
- Mock typed data
- API-ready data separation
- Mobile navigation
- No real API credentials or participant data

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Important

This is frontend/demo data only. Replace `src/data/mockData.ts` with an API/service layer when backend endpoints are available.

`CLAUDE_BUILD_PROMPT.md` contains the full prompt for Claude/Cursor to continue the implementation or integrate this UI into the actual 3SVK repository.
