### Abstract
This paper explores the convergence of Internet of Things (IoT) edge devices and real-time data analytics. By processing data closer to the source, we analyze reductions in network bandwidth usage and latency delays.

### 1. Introduction
Traditional cloud-centric IoT architectures transmit all raw telemetry data to centralized data centers, creating heavy network congestion. Edge computing shifts processing tasks to local gateways, enabling faster local decision-making.

### 2. Analytical Framework
The proposed architecture deploys lightweight streaming analytics algorithms directly onto edge nodes. This setup filters redundant sensor logs and transmits only critical aggregated metrics to the main cloud dashboard.

### 3. Conclusion
Edge-based analytics drastically minimize backhaul bandwidth requirements while improving response times for critical alerts. Future studies will investigate low-power encryption methods for constrained edge hardware.
